# 관동별곡: 잃어버린 시구

**만든이**: 박준일 (온양여자고등학교 국어 교사)

송강 정철의 가사 「관동별곡」(1580)을 **여정 → 견문 → 감상**의 흐름 그대로 걸어 보는 고등학생용 학습 게임입니다.
학생은 정철이 되어 관동 팔백 리를 원문 순서대로 지나가며, 흩어진 원문 두루마리 36개를 되찾습니다.

- 브라우저만 있으면 됩니다(설치 없음). PC 키보드와 태블릿 터치를 모두 지원합니다.
- 한 차시(35~45분)에 서장부터 종장까지 완주하도록 만들었고, 월드맵에서 장을 골라 이어 할 수 있습니다.
- 진행 상황은 **그 브라우저에만** 저장됩니다(서버로 보내지 않음).

## 실행하기

| 방법 | 설명 |
|---|---|
| 웹 주소 | https://pblsketch.github.io/gwandong-byeolgok/ (태블릿·휴대폰은 이 방법을 권장) |

### 휴대폰·태블릿에서

- **가로로** 들고 하세요. 세로로 들면 안내가 뜨고 게임이 잠시 멈춥니다.
- 메뉴를 처음 누르면 주소창이 사라진 **전체 화면**으로 바뀝니다. 타이틀 오른쪽 위 '전체 화면' 버튼으로도 켜고 끌 수 있습니다.
- 브라우저 메뉴의 **홈 화면에 추가**로 설치하면 처음부터 주소창 없이 앱처럼 열립니다. 아이폰은 이 방법으로만 전체 화면이 됩니다(Safari 공유 버튼 → 홈 화면에 추가).
- 카카오톡 같은 앱 안에서 링크를 열면 전체 화면이 막힐 수 있습니다. 메뉴에서 '다른 브라우저로 열기'를 눌러 주세요.

## 조작

오른손은 방향키, 왼손은 A·S·D에 두는 배치예요. 괄호 안의 키도 똑같이 쓸 수 있어요.

| 키보드 | 터치 | 하는 일 |
|---|---|---|
| ← → | ◀ ▶ | 걷기 (↓를 누른 채 걸으면 살금살금) |
| ↑ (Space, Z) | 점프 | 점프 · 신선의 마음이면 2단 점프, 꾹 누르면 활공 |
| A (J, X) | 붓 | 붓 공격 (신선의 마음이면 바람: 까마귀를 쫓아 버린다) |
| S (K, C) | 옥절 | 옥절 시전: 녈구름 걷기, 제단 깨우기 (관리의 마음) |
| D (L, Q, Shift) | 마음 | 관리의 마음 ↔ 신선의 마음 전환 (금강대 이후) |
| Enter / E | 화면 누르기 | 대화 넘기기 |
| Esc | Ⅱ | 멈춤 · 관동 편람 · 설정 |

붓을 Shift에 두지 않은 까닭: 윈도에서 Shift를 연달아 다섯 번 누르면 '고정 키' 창이 떠서 수업이 끊겨요.

## 구성

| 장 | 레벨 | 원문 속 장소 | 학습 장치 |
|---|---|---|---|
| 서장 | 죽림에서 궁궐로 | 창평 → 연추문 | 조작 익히기, 옥절 |
| 1장 | 부임길(말 달리기) | 평구역 → 흑수 → 섬강 → 치악 | 빠른 장소 나열 = 달리는 말 |
| | 소양강에서 회양까지 | 소양강 → 동주 북관정 → 궁왕 대궐 터 → 회양 | 연군, 회고(오작), 급장유 |
| 2장 | 만폭동과 금강대 | 만폭동 → 금강대 | 청각→시각 비유, 선학 → 신선의 마음 |
| | 진헐대에서 비로봉까지 | 진헐대 → 망고대·혈망봉 → 개심대 → 비로봉 | 4음보 석판, 비로봉은 오를 수 없음 |
| | 화룡소와 불정대 | 화룡소 → 불정대 | 삼일우로 이온 풀 살리기, 보스 '이백의 환영' |
| 3장 | 산영루에서 삼일포까지 | 산영루 → 명사길 → 총석정 → 삼일포 | 백구(물아일체), 사선의 단서 |
| | 의상대 해돋이 | 의상대 | 녈구름(간신) 걷기 |
| | 경포에서 죽서루까지 | 경포 → 강릉 → 죽서루 | 연군 ↔ 신선 갈림길(갈등 절정) |
| 4장 | 망양정 | 망양정 | 보스 '노한 고래'(파도의 비유) |
| 종장 | 월출과 꿈 | 망양정 → 꿈 | 원문 선택 / 만약에 엔딩 대비, 술빛 나누기, 명월 |

- 두루마리를 주우면 **원문 → 현대어 풀이 → 핵심 포인트 → 문제 1개**가 나옵니다. 원문을 급하게 넘긴 학생도 문제 화면의 '원문 다시 보기'(Esc)로 문제마다 한 번 두루마리를 다시 펼쳐 볼 수 있어요.
- 장이 끝나면 **여정 퍼즐**(장소 순서)과 **實/虛 분류**(원문 속 사실인지 게임 속 상상인지)를 풉니다.
- 결과 화면에서 **화자의 마음 그래프**, **오답 노트**, **완주증**(이름 입력 후 캡처 제출)을 볼 수 있습니다.

## 실제와 상상의 구분

| 표시 | 뜻 |
|---|---|
| 붉은 낙관 `原文` 두루마리 | 원문 그대로. 한 글자도 바꾸지 않았습니다. |
| 한지 상자 `풀이·해설` | 현대어 풀이와 교과서 수준의 해석 |
| 청록 상자 `虛 게임 설정` | 게임을 위해 지어낸 것(虛). 처음 나올 때 "원문에서는 →" 설명을 함께 보여 줍니다. |

- 가짜 원문은 만들지 않았습니다. 상상은 인물·사건·능력·연출에만 넣었습니다.
- AI가 그린 배경에는 글자를 넣지 않았고, 지명은 코드로만 표시합니다(가짜 현판 방지).
- 편람의 '실제와 상상' 탭에 모든 상상 요소와 대응하는 원문 내용을 모아 두었습니다.

## 선생님용

- **모든 장 열기**: 월드맵 아래 '선생님용: 모든 장 열기'를 켜면 잠긴 장도 고를 수 있습니다.
- **목숨 방식**: '새로 시작'을 누르면 고르고, 멈춤 메뉴의 '목숨'에서 언제든 바꿀 수 있습니다.

  하트는 한 목숨의 체력이에요. 하트를 다 잃으면 쓰러집니다.

  | 방식 | 쓰러지면 |
  |---|---|
  | 목숨 3개(기본) | 목숨이 하나 줄고 가까운 이정표에서 하트를 채워 이어 갑니다. 목숨은 구간마다 3개이고, 모두 잃으면 그 구간 첫머리로 돌아갑니다. |
  | 무한 목숨 | 목숨이 줄지 않고 가까운 이정표에서 이어 갑니다. 게임이 서툴러도 끝까지 갈 수 있어요. |
- **한자 병기·현대어 풀이**: 멈춤 메뉴와 두루마리 화면에서 켜고 끌 수 있습니다.

### 원문·문제 고치기

학습 내용은 모두 데이터 파일에 있어 코드를 몰라도 고칠 수 있습니다.

| 파일 | 내용 |
|---|---|
| `js/data/text.js` | 원문(`orig`), 현대어 풀이(`modern`), 어휘, 핵심 포인트, 문제, 보스 문제, 인물, 시어·상징 |
| `js/data/game.js` | 게임 설정(虛) 카드, 實/虛 분류 문항, 여정 퍼즐 순서, 지명 한자·오늘날 위치 |
| `design/원문_검증노트.md` | 원문을 대조한 출처와 판본별 차이. **사용하시는 교과서와 꼭 한 번 대조해 주세요.** |

옛한글은 대괄호 안에 자모를 적으면 게임이 조합합니다. 예: `[ㅎㆍ]다` → ᄒᆞ다, `알[ㅍㆍㅣ]` → 알ᄑᆡ, `[ㅅㄷㅗ]` → ᄯᅩ.
원문의 행은 ` / `로 나누며, `orig`와 `modern`의 행 수를 맞춰야 합니다.

## 만든 방법

- **그림**: Codex CLI의 이미지 생성(gpt-image-2)으로 직접 만들었습니다. 프롬프트는 `tools/make_prompts.py`, 생성 스크립트는 `tools/gen.ps1`·`tools/genqueue.ps1`에 있습니다.
- **가공**: `tools/process_assets.py`가 배경 제거 → 프레임 자동 검출 → 발밑 피벗 정렬 → PPU(32px) 기준 축소를 합니다.
- **배경음악**: 국립국악원 [디지털 이음](https://www.gugak.go.kr/digitaleum/front/phrase/list.do) 「국악기 디지털 음원」 악구(공공누리 제1유형, 출처표시)를 번호 순서대로 이어 붙인 실제 연주 8곡(`assets/bgm/*.mp3`)을 틉니다. 곡과 장면의 짝은 `js/data/bgm.js`에서 바꿀 수 있습니다.
  - 서장·제목 거문고 산조(중모리) · 1장 가야금 경기민요 · 2장 가야금 산조(중중모리) · 3장 가야금 경기민요 · 4장 거문고 산조(엇모리) · 보스 태평소 시나위(자진모리) · 해돋이·달밤 대금 산조(진양조) · 꿈 소금 연례악(수제천)
  - 파일을 못 읽으면 `js/core/audio.js`의 `TRACKS`에 악보로 적어 둔 창작곡을 브라우저에서 합성해 대신 연주합니다(가야금 Karplus-Strong·대금·해금·장구·북·징). 효과음은 모두 합성음입니다.
- **옛한글 글꼴**: 휴대폰마다 기본 글꼴이 달라 ᄒᆞ·ᄯᅥ 같은 옛한글이 풀어져 보이는 것을 막으려고, 옛한글 조합 기능이 있는 [Noto Serif KR](https://github.com/notofonts/noto-cjk)에서 게임에 쓰인 글자와 옛한글 자모만 남긴 글꼴(`assets/fonts/yet-serif.woff2`, 약 460KB, SIL OFL 1.1 — `assets/fonts/OFL.txt`)을 함께 넣었습니다. 원문을 고쳐 새 현대 한글·한자가 생겼다면 `python tools/build_yet_font.py`로 다시 만드세요(방법은 파일 첫머리에 있어요). 옛한글 자모는 통째로 들어 있어 새 옛한글 음절도 조합됩니다.
- **코드**: HTML5 Canvas + 순수 JavaScript(빌드 도구 없음).

## 알려진 한계

- 옛한글은 게임에 넣은 글꼴로 그립니다. 다만 `index.html`을 파일로 바로 열면 브라우저가 글꼴 파일을 막아, 기기 글꼴(윈도 '맑은 고딕' 등)로 대신 그립니다. 휴대폰·태블릿은 웹 주소로 여세요.
- 원문은 여러 자료를 대조했지만 판본(성주본·이선본 등)과 교과서에 따라 표기가 조금씩 다릅니다. 차이는 검증 노트에 정리했습니다.
- 화자의 마음 그래프 값은 교과서 해석을 따른 대략의 위치이며, 해석의 정답표가 아닙니다.
