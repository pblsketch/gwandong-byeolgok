# 관동별곡: 잃어버린 시구 — 기획서 v1 (인터뷰 확정)

## 확정 사항

| 항목 | 결정 |
|---|---|
| 형식 | **기행 어드벤처**: 관동 지도 월드맵(여정) + 장소별 사이드뷰 체험(견문) + 속마음 대화·선택(감상) |
| 전투 | 가벼운 전투 유지: 먹물 요괴(망각귀의 부하, 虛)를 붓으로 물리친다 |
| 주인공 | 정철 본인(화자) |
| 원문 | 옛한글 원문 + 현대어 풀이, 한자 병기 켜기/끄기 |
| 범위 | 전문(서사~결사) |
| 분량 | 한 차시 완주(35~45분), 장 선택 가능 |
| 기기 | PC(키보드) + 태블릿(터치 버튼) |
| 화풍 | 하이브리드: 픽셀 캐릭터·발판 + 수묵 배경 |
| 엔딩 | 원문 엔딩 + '만약에 엔딩'(虛, 대비용) |
| 배포 | GitHub Pages (배포 직전에 확인) |
| 강조점 | 여정 순서, 화자의 갈등과 해소, 시어의 상징과 표현법, 고사와 원문 해석 (전부) |

## 표시 규칙 (실제와 상상의 구분)

- **가짜 원문은 만들지 않는다.** 원문은 한 글자도 각색하지 않는다.
- 대사마다 종류를 붙인다.
  - 📜 `orig` 원문 두루마리 — 한지 배경, 붉은 낙관, 명조체
  - 📖 `note` 해설(현대어 풀이, 교과서 수준 해석) — 한지 배경, 먹색 테두리
  - 🎮 `game` 게임 대사·설정(虛) — 청록 테두리, 고딕체, `게임 설정` 태그
- AI가 그린 배경에는 글자를 넣지 않는다. 지명은 코드로만 표시한다(가짜 현판 방지).
- 상상 요소는 처음 나올 때 「잠깐! 이건 게임 설정」 카드와 "원문에서는 → …"을 함께 보여 준다.

## 두 마음 시스템

| | 관리의 마음 (옥절) | 신선의 마음 (학의 깃) |
|---|---|---|
| 해금 | 서장(연추문, 옥절) | 2장 금강대(선학) |
| 능력 | 붓 공격, 정화(삼일우 제단, 녈구름 걷기) | 2단 점프, 활공, 공격 불가 |
| 원문의 뿌리 | 연군·애민·우국·선정 | 풍류·탈속·신선 동경 |

- 장소마다 원문 해석에 따른 **화자의 마음 값**을 두고, 감상 지점의 '마음 읽기' 문제를 맞히면 **마음 그래프**에 점이 찍힌다. 결과 화면에서 여정 전체의 마음 흐름(→ 죽서루 갈등 절정 → 결사 해소)을 보여 준다.

## 장 구성

| 장 | 레벨 | 장소(원문 순서) | 핵심 기믹 |
|---|---|---|---|
| 서장 | P1 죽림에서 궁궐로 | 창평 죽림 → 연추문·경회 남문 | 튜토리얼, 옥절 획득, 첫 먹물 요괴 |
| 1장 | 1A 부임길(말 달리기) | 평구역 → 흑수 → 섬강 → 치악 | 자동 달리기 러너, 이정표 순서 |
| | 1B 소양강~회양 | 소양강 → 동주 북관정 → 궁왕 대궐 터 → 회양 | 오작 떼(虛 공격), 급장유 카드 |
| 2장 | 2A 만폭동·금강대 | 만폭동 → 금강대 | 폭포 오르기, 선학 → 학의 깃 해금 |
| | 2B 봉우리 | 진헐대 → 망고대·혈망봉 → 개심대 → 비로봉 | 음보 석판, 비로봉은 오를 수 없음 |
| | 2C 화룡소·불정대 | 화룡소 → 불정대 | 삼일우로 이온 풀 살리기, 외나무다리, **보스: 이백의 환영** |
| 3장 | 3A 해안 | 산영루 → 명사길·해당화 → 총석정 → 삼일포 | 백구 놀래키지 않기, 사선봉 돌기둥, 단서 찾기 |
| | 3B 의상대 | 의상대 일출 | 녈구름 걷어 해 지키기 |
| | 3C 경포~죽서루 | 경포 → 강릉 → 죽서루 | 배 타기, 죽서루 갈림길(연군 ↔ 신선) |
| 4장 | 4 망양정 | 망양정 | **보스: 노한 고래**(파도의 비유를 실체화, 虛) |
| 종장 | E 꿈 | 월출 → 꿈속 신선 | 술 나누기 비행(억만 창생), 만약에 엔딩, 명월 |

장이 끝날 때마다: **여정 퍼즐**(장소 순서) + **實/虛 분류**.

## 기술

- HTML5 Canvas + 순수 JS(클래식 스크립트, 빌드 없음) → 더블클릭 실행과 GitHub Pages 모두 가능
- 내부 해상도 640×360, PPU 32, 플레이어 프레임 48×48
- 원문·풀이·퀴즈·편람은 `js/data/`의 데이터 파일로 분리
- 옛한글 입력 규칙: `[ㅎㆍ]`처럼 대괄호 안에 자모를 적으면 실행 시 옛한글 음절로 조합
- 사운드: WebAudio 합성(국악 5음계)
