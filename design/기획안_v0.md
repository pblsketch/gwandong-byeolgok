# 관동별곡 학습 게임 기획안 v0 (인터뷰 전 초안)

> 참고 영상: 「[시즌 3] 게임을 만들고 싶을 때 어떻게 해야 할까? 오퍼스 5.5로 게임 만들기」(편집자P, 2026-09-24)
> 영상 핵심: GPT 이미지로 스프라이트 시트 제작(발밑 피벗·동작별 프레임 수·투명 배경) → PPU 32px 기준 타일 아틀라스 → 캔버스 웹 플랫포머 → 히트스톱·넉백·화면 흔들림·파티클로 손맛 살리기

## 1. 한 줄 콘셉트

**「관동별곡: 잃어버린 시구」** — 망각귀(忘却鬼)가 흩어 놓은 관동별곡의 시구를 되찾으며 송강 정철의 관동 800리 여정을 직접 걷는 2D 횡스크롤 액션 플랫포머.

- 학생은 1580년(선조 13) 강원도 관찰사로 부임한 정철이 되어, **실제 여정 순서대로** 스테이지를 밟는다.
- 걷고, 뛰고, 싸우는 재미는 영상의 기법을 그대로 가져오고, **정답을 맞히는 순간에도 히트스톱과 화면 흔들림을 넣어** 공부하는 동작 자체에 손맛을 준다.

## 2. 학생들이 어려워하는 지점 → 게임 장치

| 어려워하는 것 | 게임 장치 | 왜 기억에 남는가 |
|---|---|---|
| **여정 순서·지명** (만폭동→금강대→진헐대…) | 스테이지 순서 = 실제 여정. 이정표에 원문 지명과 오늘날 지역을 함께 표시. 장이 끝날 때마다 **여정 지도 퍼즐** | 몸으로 지나간 순서는 외운 순서보다 오래간다 |
| **고어 원문 해석** | **시구 두루마리** 수집 → 원문, 현대어 풀이, 한 줄 포인트 | 수집욕이 곧 복습이 된다 |
| **3·4조 4음보 율격** | **음보 블록 다리**: 흩어진 음보 4개를 순서대로 밀어 넣어야 다리가 놓인다 (예: 강호애 / 병이 깁퍼 / 듁님의 / 누엇더니) | 율격을 손으로 조립한다 |
| **화자의 내적 갈등(신선 ↔ 관리)과 해소** | **두 마음 시스템**: 신선의 마음(학의 깃: 활공·2단 점프) ↔ 관리의 마음(옥절: 정화·공격)을 바꿔 가며 길을 연다. 결사의 꿈 장면에서 최종 선택 | 추상적인 '갈등'을 조작으로 체감한다 |
| **시어의 상징** | 상징이 곧 기믹이 된다. 의상대에서 **녈구름을 걷어야 해가 보이고**(간신), 화룡소에서 **삼일우로 음애의 이온 풀을 살린다**(애민·선정) | 상징의 뜻을 행동으로 수행한다 |
| **고사·인물**(급장유, 임포, 공자, 이백, 사선, 홍장) | **인물 카드** 수집, 해당 장소에서 획득 | 인물과 장소가 짝지어진다 |
| **표현법**(대구·직유·과장·설의·영탄) | 보스전 **시구 대결**: 보스가 원문 구절을 쏘면 표현법이나 의미를 골라 되받아친다. 정답이면 히트스톱과 카운터 | 오답은 피격, 정답은 타격감 |
| **헷갈리는 포인트**(비로봉에 올랐나?) | **함정 체험**: 비로봉 정상은 끝까지 오를 수 없다. 오르려 하면 "오르지 못하거니 나려가미 고이할가" 두루마리가 뜬다 | 틀리게 기억할 여지를 게임이 막는다 |

## 3. 스테이지 구성 (서장 + 4장 + 종장, 장당 6~8분)

| 장 | 제목(원문 인용) | 여정 | 대표 기믹 · 보스 |
|---|---|---|---|
| 서장 | 성은이야 가디록 망극하다 | 창평 죽림 → 연추문·경회 남문 | 조작 튜토리얼, **옥절** 획득 |
| 1장 | 고신 거국에 백발도 하도 할샤 | 평구역 → 흑수 → 섬강 → 치악 → 소양강 → 동주 북관정 → 회양 | 소양강 물길(연군), 궁왕 대궐 터의 오작 떼(흥망 무상), 회양에서 **급장유 카드** |
| 2장 | 들을 제난 우레러니 보니난 눈이로다 | 만폭동 → 금강대 → 진헐대 → 망고대·혈망봉 → 개심대 → 비로봉(못 오름) → 화룡소 → 불정대 | 폭포 활공, 선학 탑승, 삼일우, **보스: 이백의 환영**(십이폭포 vs 여산폭포 시구 대결) |
| 3장 | 이도곤 가잔 데 또 어듸 잇닷 말고 | 산영루 → 해당화 길 → 총석정 → 삼일포 → 의상대 → 경포 → 강릉 → 죽서루 | 총석정 돌기둥 발판, 삼일포 단서 찾기, 일출과 녈구름, 죽서루 **갈림길**(한강 목멱 ↔ 선사·단혈) |
| 4장 | 오월 장천의 백설은 므사 일고 | 망양정 | **보스: 노한 고래**(파도를 비유한 말을 게임에서 실체화) |
| 종장 | 명월이 천산만락의 아니 비친 데 업다 | 망양정 월출 → 꿈 | 꿈속 신선과의 대화, 술을 **억만 창생에게 나누는 선택**, 명월 엔딩 → 인증서 |

## 4. 실제와 상상을 구분하는 장치 (요구사항 4)

**원칙: 가짜 원문은 만들지 않는다.** 원문 구절은 한 글자도 각색하지 않고, 상상은 인물·사건·능력·연출에만 넣는다. 그럴듯한 가짜 시구는 오답 기억을 만들 위험이 크기 때문이다.

| 구분 | 표시 방식 | 들어가는 내용 |
|---|---|---|
| 📜 **원문(實)** | 한지 두루마리 배경, 붉은 낙관 `原文`, 명조체 | 원문 구절, 현대어 풀이, 교과서 수준의 해석 |
| 🎮 **게임 상상(虛)** | 청록 테두리, `게임 설정` 태그, 고딕체 | 망각귀, 보스전, 캐릭터 애드리브, 능력 |

- 상상 요소가 처음 나올 때 **「잠깐! 이건 게임 설정」** 카드가 뜨고, "원문에서는 → …"을 바로 붙인다.
- 장이 끝나면 **實/虛 분류 미니게임**: 이번 장에서 본 요소를 두 바구니에 나눠 담는다.
- **관동 편람(도감)**의 모든 항목에 實/虛 도장을 찍는다.

| 게임 요소 | 구분 | 원문에서는 |
|---|---|---|
| 망각귀·먹물 요괴 | 虛 | 등장하지 않는다. 게임의 적이다 |
| 붓으로 싸우는 정철 | 虛 | 싸우는 장면은 없다 |
| 옥절 | 實(소품) · 虛(능력) | 관찰사의 신표. "옥절이 알패 셧다" |
| 선학 타고 활공 | 虛 | 금강대의 선학은 신선 풍류와 임포(서호 옛 주인)를 떠올리게 하는 소재 |
| 녈구름 걷어내기 | 기믹 虛 · 의미 實 | 녈구름은 임금의 총명을 가리는 간신의 상징 |
| 이백과의 시구 대결 | 虛 | "이적선이 여기 와서 다시 논하면 여산이 낫다 말 못 하리라" |
| 노한 고래 보스 | 虛 | 고래는 거센 파도를 비유한 표현 |
| 꿈속 신선의 술 | 實 | 결사의 꿈 장면 그대로 |

## 5. 게임 시스템

- **조작**: ←→ 이동 · Space 점프 · J 붓 공격 · K 마음 전환 · E 두루마리 읽기 (태블릿용 터치 버튼 병행)
- **부담 낮추기**: 하트 3개, 체크포인트 즉시 부활, 난이도 '쉬움'은 무적. 게임 실력이 학습을 가로막지 않게 한다.
- **점수·등급**: 두루마리 수집률 + 퀴즈 정답률 → 등급(유생 → 관찰사 → 상계 진선)
- **저장**: 브라우저에 장별 진행 저장, 장 선택 가능
- **결과 화면**: 완주 인증서 + 오답 노트 (캡처해서 제출 가능)

## 7. 기술 구성

- HTML5 Canvas + 순수 JavaScript (빌드 도구 없음)
- 내부 해상도 480×270 → 정수 배율 확대로 픽셀을 선명하게 유지
- **원문·풀이·퀴즈를 데이터 파일로 분리** → 선생님이 교과서 표기에 맞춰 직접 고칠 수 있음

## 8. 인터뷰로 정할 것

1. 장르(플랫포머 / 탑다운 RPG / 비주얼노벨)
2. 플레이 환경과 분량(차시)
3. 수록 범위와 원문 표기 방식(옛한글 / 현대 표기)
4. 화풍(시안 3종)
5. 학습 목표 우선순위
6. 상상 요소의 수위
7. 배포 방식, 결과 확인 방식
